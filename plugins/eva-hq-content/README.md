# eva-hq-content

Het contentsysteem van EVA HQ, Module 2. Zes skills die samen het hele traject dekken: verzamelen, kiezen, plannen, schrijven en hergebruiken.

| Skill | Aanroep | Wat het doet |
|---|---|---|
| briefing | `@briefing` | Vaknieuws op je keywords, naar een staging-bestand |
| inspire | `@inspire` | Content-inspiratie van Instagram, YouTube en je eigen creators, naar een staging-bestand |
| ideate | `@ideate` | Maakt van de staging-bestanden content-ideeën en zet je selectie in de Inspiratiedatabase |
| planner | `@planner maand`, `@planner week`, `@planner review` | Het maandplan in je Content-database in Notion: skelet, weekvulling, review |
| content-creator | `@content` | Schrijft één post, vanuit een idee, een opdracht of een slot uit het maandplan |
| repurpose | `@repurpose` | Haalt meerdere posts uit één stuk longform, ook voor een oogst-slot uit het maandplan |

## Wat je nodig hebt

- Je Content Manager-projectmap met het fundament uit Module 2 (`identiteit.md`, `strategie.md`) en voor de planner `planner.md` uit de Content Planner-lessen.
- De save-skill uit Module 1, geïnstalleerd als losse skill. Die bevat de link van je Business HQ-pagina; alle skills in deze plugin vinden je Notion-databases via die ene link.
- De koppelingen die de lessen noemen: Notion; Apify voor briefing en inspire; Composio (Instagram) als je die route gebruikt.

## Let op bij overstappen

Had je briefing, inspire, ideate, content-creator of repurpose al als losse skill geïnstalleerd? Verwijder die losse versies na het installeren van deze plugin, anders staat elke skill twee keer in je lijst.
