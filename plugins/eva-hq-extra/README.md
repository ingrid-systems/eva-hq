# eva-hq-extra

De skills uit de module Extra van EVA HQ.

| Skill | Aanroep | Wat het doet |
|---|---|---|
| indexeer | `@indexeer` | Zet een reeks in je Bronarchief goed: indextabel, distillaat (REEKS.md) en hoofdindex. Bij reeksen met `Klanttaal: ja` in de README zet hij de uitspraken van klanten uit nieuwe calls in je database Klanttaal. |

## Wat je nodig hebt

- Een Bronarchief, opgezet met de prompt uit de les "Je bronarchief opzetten", als gekoppelde map.
- De save-skill, geïnstalleerd als losse skill (de les "Skill inrichten: Save All (@save)"). Die bevat de link van je Business HQ-pagina; via die link vindt @indexeer de database Klanttaal en de optionele Notion-spiegel.
- Voor klanttaal: de database Klanttaal op je Business HQ-pagina. Die maakt de Voice of the Customer-prompt uit de les "Jouw boodschappenlijst" aan. Staat hij er niet, dan slaat @indexeer de klanttaal-stap over.

## Let op bij overstappen

Had je indexeer al als losse skill geïnstalleerd? Verwijder die losse versie na het installeren van deze plugin, anders staat de skill twee keer in je lijst.
